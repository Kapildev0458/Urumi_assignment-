## Tech decisions so far

| Area | Decision |
|---|---|
| Local k8s | k3d, cluster `urumi`, k3s `v1.35.5-k3s1` (same as VPS) |
| Ingress / domains | Traefik (bundled with k3s); `*.127.0.0.1.nip.io`; hosts-file fallback |
| Charts | Umbrella `charts/platform` (values-local / values-prod) + one chart per component |
| Store | MariaDB 11.4 StatefulSet + `wordpress:7.1.3-php8.3-apache`, `wp-content` on a PVC, WP-CLI setup hook Job |
| Woo MCP ↔ store | WooCommerce REST API with a key generated by Helm into a Secret |
| URLs | Storefront `store.<domain>`; dashboard `/`, API `/api`, gateway MCP `/mcp` on `app.<domain>` |
| Apps | Node.js 20 + TypeScript, official MCP SDK 1.32.1 (Streamable HTTP, stateless), React 19 + Vite dashboard on nginx-unprivileged |
| Gateway DB | PostgreSQL 17 StatefulSet; schema created at startup under an advisory lock |
| Collision scheme | `<server>__<tool>`; server names are slugs without `__` |
| Upstream credentials | AES-256-GCM in the DB, key in the Helm-generated `urumi-gateway-secrets` |
| Chat agent | Loop runs in the gateway as the logged-in user; providers: Anthropic SDK (`claude-opus-5-5`) or OpenAI-compatible; key in the non-Helm Secret `urumi-gateway-llm` |
| Third upstream | `time-mcp` (self-written: current_time, convert_time, date_diff) |
